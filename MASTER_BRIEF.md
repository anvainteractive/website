# ANVA Website Master Brief

Build the official ANVA website as a modern technology / entertainment company website with Roblox at the center of its product ecosystem.

Primary navigation:
- Home
- Assistance Hub
- Status
- Events
- ANVA Hub

Core design:
- white-first
- black / charcoal typography
- generous whitespace
- thin dark borders
- large rounded corners
- calm Apple/Google-inspired interaction philosophy without copying either brand
- selective Liquid Glass
- no neon
- no gaming-dashboard aesthetic
- no emojis
- local SVG icons
- smooth route/tab transitions
- responsive desktop/tablet/mobile design

Core product content:
- ANVA Horizon Resort
- The Game
- ANVA Network
- ANVA Studios
- ANVA Interactive (planned 2027)
- Assistance Hub / Genius Helpers / Genius Forum (Coming Soon)
- scripted Roblox models/objects/systems planned through ANVA Studios in 2027

ANVA Hub:
- account-free update feed
- title, category, date, tags, body
- like, view, share
- direct post hash links
- no fake global metrics
- local storage until a backend exists

Status:
- configurable service states
- ANVA Horizon Resort
- The Game
- ANVA Network
- ANVA Assistance Hub

Events:
- simple milestone/calendar timeline
- content defined in JavaScript data
- no invented third game until ANVA names it

Technical:
- static HTML/CSS/JS
- works locally and on GitHub Pages
- no build step
- no external mandatory API
- accessible focus states
- reduced-motion support
- SEO/OpenGraph basics
